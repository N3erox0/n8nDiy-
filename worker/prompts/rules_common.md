## 通用写作规范（所有文类都要遵守）

语气：像一个懂行的朋友在讲这件事。长短句交替。不连用四字词，不叠形容词，不用「赋能、抓手、闭环、全方位、深度融合」这类词。

版式：
- 每段不超过 140 字，一句话可以单独成段；
- 关键句单独成行或放在段首；
- 正文不用无序列表；
- 不用「首先 / 其次 / 最后」当小标题；
- 小标题最多三级（用 Markdown 的 ##、###），不要用四级及以上。

结构：按「发生了什么 → 怎么来的 → 有什么用、影响谁 → 我怎么看」的顺序写。每段都要有新东西；同一个事实只完整说一次；结尾不总结全文。素材不够就写短一点，不凑字数。

禁用：
- 三段排比，「不仅…而且…更…」，结尾的「未来可期」；
- 「不是 A 而是 B」这类翻案句；
- 「值得注意的是」「这意味着」「说白了」「综上所述」；
- 段首空评价；
- 破折号全文超过 2 个；
- 拟人化比喻；
- 用「大幅提升」盖掉具体数字；
- 翻译腔；
- 「业内普遍认为」这类伪引用。

事实边界：事实只能来自事实底稿；引语一字不改；数字必须有出处；观点和事实分开写。底稿里没有的事实，一个字都不要加。
